Home screen structure

1Header — Little Lemon logo centred, profile avatar on the right (opens Profile).

2Hero — restaurant name, location (Chicago), short description, hero image and a search bar that filters dishes by name.

3Menu breakdown — “Order for delivery!” and a horizontal bar of category buttons (Starters, Mains, Desserts, Drinks). Selected buttons are highlighted; several can be active.

4Food menu list — each item shows name, two-line description, price and a thumbnail.

Onboarding

Shown on first launch only. Three pages (first name → last name → email), each with validation and a Next button; the last page finishes and opens Home.

Profile

Pre-filled with the onboarding data. Avatar, phone and notification preferences can be edited. Save changes persists data across restarts; Log out clears all stored data and returns to Onboarding.

Navigation

Native stack navigator — Profile has a Back button to Home.
